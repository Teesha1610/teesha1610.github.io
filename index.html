Projects

taskhive

Python · SQLite · pytest · Hypothesis · GitHub Actions

A zero-dependency durable task queue library, with crash recovery and a cross-platform performance fix backed by measurement.

  • At-least-once delivery, lease-based crash recovery, and exponential backoff with full jitter. Packaged with a command-line entry point and complete type annotations.
  • Atomic task claiming across concurrent workers using a single UPDATE ... RETURNING inside a BEGIN IMMEDIATE transaction — verified with 8 threads racing for 200 tasks and zero duplicate delivery.
  • Three defects surfaced only by the 10-configuration CI matrix, including the Windows timer-granularity collapse above.
  • Unit and property-based tests with pytest and Hypothesis, covering the concurrency and failure paths that example-based tests miss. Strict type checking with mypy, linting with ruff.

Local AI Assistant

Python · Ollama · FastAPI · RAG · LLM security

A conversational assistant that runs entirely offline, answers only from your own documents, and treats those documents as untrusted input.

  • Runs on locally hosted open-source models through the Ollama REST API, streaming tokens to the browser over server-sent events. No external API, no key, no network.
  • Retrieval over local documents using embeddings and a cosine similarity index, with every answer grounded in and cited to its source file.
  • A guardrail layer over retrieved content: PII and secret redaction, indirect prompt-injection detection, context delimiting, and per-session rate limiting.
  • Findings are surfaced to the user rather than silently dropped — a tool that quietly edits your own files is a tool you stop trusting.

github.com/Teesha1610/local-ai-chatbot

GitHub Analytics Dashboard

Python · FastAPI · Node.js · REST APIs

Developer analytics over the GitHub REST API — and a study in the parts of that API the documentation glosses over.

  • Aggregates repository metrics: commit trends, bus factor, pull request cycle time, issue responsiveness, and contribution heatmaps.
  • Handles three non-obvious API behaviors: 202 responses from statistics endpoints that compute asynchronously, secondary rate limits returning 403 with Retry-After, and ETag conditional requests so revalidation costs no quota.
  • Two interfaces over one aggregation layer: a browser dashboard with hand-written SVG charts that needs no build step, and a zero-dependency Node.js command-line tool.
